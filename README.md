# Data Analytics Assignment Summary

## Introduction

The Data Analytics Assignment focused on analyzing data and transforming raw information into meaningful insights using Microsoft Excel, Power BI, Tableau, and MySQL. The main objective was to develop practical data analysis skills, understand business data, identify trends and patterns, and present information through effective visualizations and reports.

## Tools and Technologies Used

**1. Microsoft Excel:** Excel was used for data cleaning, data organization, calculations, and analysis. Functions, formulas, sorting, filtering, and lookup techniques helped process the dataset and prepare it for further analysis. Excel also supported the creation of charts and summary reports.

**2. MySQL:** MySQL was used to store, retrieve, filter, and analyze structured data. SQL queries were written using commands such as SELECT, WHERE, GROUP BY, ORDER BY, and JOIN to extract relevant information, perform calculations, and identify trends within the dataset.

**3. Power BI:** Power BI was used to create interactive dashboards and reports. Key Performance Indicators (KPIs), charts, graphs, and other visual elements helped present important business metrics. Filters and slicers enabled users to explore the data from different perspectives.

**4. Tableau:** Tableau was used for data visualization and dashboard development. Different charts and graphs were created to identify patterns, compare performance, and communicate analytical findings clearly and effectively.

## Project Workflow

The assignment followed a systematic process. First, the dataset was collected and examined to understand its structure and contents. Next, data cleaning and preprocessing were performed to improve data quality and consistency. MySQL queries were then used to retrieve and analyze relevant information. Excel supported calculations and further analysis, while Power BI and Tableau were used to develop visual reports and interactive dashboards.

## Conclusion

This assignment provided valuable practical experience in data analysis, database management, and business intelligence. Working with Excel, MySQL, Power BI, and Tableau improved my technical skills and helped me understand how to convert raw data into useful business insights. Overall, the assignment strengthened my analytical thinking, problem-solving, and data visualization skills, which are important for a career as a Data Analyst.
